# @vitreakit/svelte

Svelte 5 components on top of [`@vitreakit/core`](../core).

```ts
import { Button } from "@vitreakit/svelte/button";
import * as Dialog from "@vitreakit/svelte/dialog";
import { GlassFilters, Segmented, press } from "@vitreakit/svelte";
```

Each shadcn-style component has its own entry point; the root entry has Vítrea's own components and the motion and glass helpers. Render `<GlassFilters />` once in the root layout.
